# Conker: Live & Reloaded для Switch, Linux і Windows

[English](README.md) · [Документація](docs/README.md) (англійською)

Неофіційний порт оригінальної гри для Xbox **Conker: Live & Reloaded** (Rare, 2005). Вона працює
нативно на Nintendo Switch з кастомною прошивкою, на Linux і на Windows. Це не емулятор: скрипт
перетворює x86-код гри на C і збирає його для вашої платформи. Команди відеочипа Xbox
виконуються через Vulkan (Switch) або OpenGL (усі платформи).

> **У цьому репозиторії немає коду гри та даних гри.** Готові збірки є в
> [Releases](https://github.com/rashevskyv/conker-lr-recomp/releases). Вони містять код, створений з гри, але не містять даних гри: вам
> потрібна **власна розпакована копія** гри. Можна також зібрати програму самостійно зі свого
> `default.xbe`.

**Стан:** одиночна гра придатна до проходження. На Switch вона працює стабільно на 30 fps. Є
справжнє 16:9, 60 fps (експериментально), вільна камера і вікно налаштувань у грі.
Мультиплеєр і Xbox Live не працюють.

## Що потрібно

- **Ваша власна** копія гри для оригінального Xbox: версія **retail NTSC (Північна Америка)**.
  SHA-1 її файлу `default.xbe` має бути таким: `2232a1b3874d67b4bb4cf53a940420d2dab59535`.
  Інші версії не перевірено. Скрипт збирання зупиняється на них.
- Комп'ютер для збирання: 16 ГБ пам'яті і близько 20 ГБ вільного місця на диску.
- **Switch:** консоль з [Atmosphère](https://github.com/Atmosphere-NX/Atmosphere) і hbmenu та
  5 ГБ вільного місця на картці microSD.
- **Linux і Windows:** відеокарта з OpenGL 3.3. Геймпад не обов'язковий: працює клавіатура.

## Як встановити

**Просто:** завантажте свою платформу з [Releases](https://github.com/rashevskyv/conker-lr-recomp/releases), розпакуйте і покладіть поруч
папку з розпакованою грою (див. примітки релізу). **Або зберіть самі** зі своєї копії гри, як
нижче. Докладніше: [Збирання](docs/building.md) (англійською).

### Крок 1. Розпакуйте диск

Розпакуйте образ диска в папку, наприклад програмою
[extract-xiso](https://github.com/XboxDev/extract-xiso):

```bash
extract-xiso -x Conker.iso -d conker-disc
sha1sum conker-disc/default.xbe
```

У папці близько 881 файлу (4,5 ГБ). Перевірте, що SHA-1 збігається з наведеним вище.

### Крок 2. Отримайте цей репозиторій

Склонуйте його і зайдіть у папку. На Windows з WSL2 клонуйте **всередині** Linux (`~/`, не
`/mnt/c/`). Диски Windows там дуже повільні.

### Крок 3. Збирання і встановлення

<details open>
<summary><b>Nintendo Switch</b></summary>

З Docker (найпростіше). Перше збирання триває близько 1 години.

```bash
docker build -t clx-build .
docker run --rm --user "$(id -u):$(id -g)" -e HOME=/tmp \
  -v "$PWD:/src" -v "$HOME/conker-disc:/xbe:ro" \
  clx-build ./build_from_xbe.sh /xbe/default.xbe
```

Без Docker: див. [Збирання](docs/building.md).

Далі:

1. Скопіюйте вміст `out/sdmc/` у корінь картки microSD.
2. Скопіюйте папку з розпакованим диском у `sdmc:/switch/clx/game/`.
   Файл `sdmc:/switch/clx/game/default.xbe` має існувати.
3. Запустіть застосунок з **title takeover**: утримуйте **R**, відкриваючи будь-яку гру, потім
   виберіть застосунок у hbmenu. (У режимі Album пам'яті не вистачає.)
4. Дайте першому запуску завершитися. Він компілює шейдери і кілька хвилин може гальмувати.

Користуйтеся `clx-vulkan.nro` (рекомендовано). `clx.nro` — запасний варіант на OpenGL.
</details>

<details>
<summary><b>Linux</b></summary>

```bash
sudo apt install build-essential cmake ninja-build pkg-config git python3-pip \
  libsdl2-dev libssl-dev libepoxy-dev
pip3 install --break-system-packages capstone==5.0.7 Pillow
VARIANTS=linux ./build_from_xbe.sh ~/conker-disc/default.xbe
out/linux/clx.sh ~/conker-disc
```

Папка `out/linux` самодостатня. Гра зберігає дані в папку диска, тож беріть папку, у яку можна
писати.
</details>

<details>
<summary><b>Windows</b></summary>

1. Встановіть [MSYS2](https://www.msys2.org) (наприклад, `winget install MSYS2.MSYS2`).
2. У PowerShell, у папці репозиторію:

   ```powershell
   .\build_from_xbe.ps1 C:\conker-disc\default.xbe -Install
   .\out\windows\clx.bat C:\conker-disc
   ```

Папка `out\windows` самодостатня. Її можна перенести. Гра зберігає дані в папку диска, тож
беріть папку, у яку можна писати. Повідомлення програми йдуть у `clx_log.txt` поруч із `clx.bat`.
</details>

## Як грати

**Вікно налаштувань** можна відкрити будь-коли. Воно зберігає `clx_options.txt`.

| Платформа | Кнопка налаштувань |
|---|---|
| Switch | **−** (Minus) |
| Геймпад на ПК | **Back** / **View** |
| Клавіатура на ПК | **Esc** |

### Керування

| Гра | Switch | Геймпад на ПК | Клавіатура на ПК |
|---|---|---|---|
| Рух | лівий стік | лівий стік | W A S D |
| Камера | правий стік | правий стік | стрілки або I J K L |
| A / B / X / Y | A / B / X / Y | A / B / X / Y | Space / E / Q / R |
| White / Black | L / R | лівий / правий бампер | Z / X |
| Тригери | ZL / ZR | тригери | Left Shift / Left Ctrl |
| Start | + | Start | Enter |
| Пропустити відеоролик | + , A або ZL | Start, A або лівий тригер | Enter, Space або Left Shift |

Геймпад можна підключати і відключати під час гри. Клавіатура завжди працює як геймпад 1. У вікні
налаштувань видно, який геймпад використовується, можна **переназначити кнопки геймпада і
клавіатури**, скинути керування і **вийти з гри**. (Або змінити `key_a=Return` і `pad_a=b` у
`clx_options.txt`.) Усі елементи керування і клавіші: див.
[Налаштування і керування](docs/settings-and-controls.md) (англійською).

### Параметри

По одному `ключ=значення` в рядку у `clx_options.txt` (Switch: `sdmc:/switch/clx/`; ПК: поруч із
`clx.sh` / `clx.bat`).

| Ключ | За замовчуванням | Значення |
|---|---|---|
| `aspect` | `4:3` | `16:9` — ширший огляд, а не розтягування. HUD і меню розтягнуті. |
| `fps` | `30` | `60` — експериментально. Потрібен перезапуск. |
| `camera` | `classic` | `free`: камера не повертається сама за спину Конкеру. |
| `camera_invert_y` | `0` | `1`: інвертувати правий стік вгору/вниз. |
| `bubble` | `wide` | Поле субтитрів: `wide` — 40 символів x 6 рядків; `classic` — оригінальні 20 x 4. |
| `volume` | `100` | Гучність звуку, від 0 до 100. |
| `fps_counter` | `0` | `1`: показувати цифри FPS. |
| `scale_handheld`, `scale_docked` | `150`, `225` | Масштаб рендерингу на Switch у відсотках. На ПК `scale_handheld` — масштаб рендерингу (за замовчуванням 100). |
| `aniso`, `fxaa` | `16`, `1` | Анізотропна фільтрація і FXAA (застосунок Vulkan). |
| `vignette` | `1` | `0`: без затемнених країв екрана в рівнях. |
| `grass_wind` | `1` | Далека трава гойдається від вітру, як близька; `0`: як у грі. |
| `language` | `english` | Мова меню і субтитрів: `english`, `french`, `german`, `spanish`, `italian`, `japanese` (озвучення лишається англійським). Потрібен перезапуск. |

## Вирішення проблем

- **Гра зависла на екрані завантаження (0 fps).** Ви вийшли під час першого запуску. Видаліть
  папку кешу і запустіть знову: `sdmc:/switch/clx/save/Cache` на Switch, папка `CACHE` у папці
  диска на ПК.
- **Застосунок для Switch вилітає або не вистачає пам'яті.** Використайте title takeover:
  утримуйте **R**, відкриваючи гру.
- **«Failed to load default.xbe» на ПК.** Вкажіть папку диска: `clx.sh <папка>` або
  `clx.bat <папка>`.
- **Скрипт каже, що SHA-1 неправильний.** Потрібна версія retail NTSC (Північна Америка).

Більше: [Вирішення проблем](docs/troubleshooting.md) (англійською).

## Тестування: що надіслати разом зі звітом про помилку

Це тестова збірка. Якщо на Switch щось іде не так, надішліть ці чотири файли з
`sdmc:/switch/clx/` на картці microSD:

| Файл | Що це |
|---|---|
| `clx_log_vk.txt` | журнал останнього запуску (`clx_log.txt`, якщо запускали застосунок OpenGL) |
| `clx_log_vk.prev.txt` | журнал попереднього запуску (виліт часто в ньому) |
| `clx_options.txt` | ваші налаштування |
| `clx_env.txt` | додаткові перемикачі |

Також напишіть версію з hbmenu (наприклад `0.54.257ded-vk`), де в грі це сталося і що ви
робили перед цим. Не надсилайте файли гри.

## Поширені запитання

**Чи містять завантаження гру?** Ні. Там немає даних гри (файлів диска, текстур, звуку). Потрібна
ваша власна розпакована копія гри, retail NTSC (Північна Америка). Самі програми містять код,
створений з гри. Якщо хочете, зберіть їх самі зі свого `default.xbe`.

**Чи можна PAL або іншу версію?** Не перевірено. Збирання зупиняється, якщо XBE не збігається.

**Чи працює це в емуляторі?** Застосунок Switch на OpenGL працює в Eden. Застосунок Vulkan
потребує справжньої консолі. На ПК гра працює нативно, без емулятора.

**Чи можливі мультиплеєр або Xbox Live?** Ні. Мета — одиночна гра.

**Чи безпечно 60 fps?** Це експериментально. Деякі часові залежності (ролики, фізика) можуть
відрізнятися.

**Чи можна перекласти гру?** Так. Див. [Переклад гри](docs/translation.md) (англійською).
Широке поле субтитрів (`bubble=wide`) дає місце довшим рядкам.

**Чи є звук у версії для ПК?** Він вбудований, але звук на ПК ще не добре перевірено.
